# 形策 · 习近平党建思想中的战略思维

课堂展示用单页网站，档案文献风：纸色、墨黑、正红。

## 打开方式

直接用浏览器打开 `dangjian-strategic-thinking.html` 即可（单文件，无构建步骤、无外部依赖，字体缺失时回退系统字体）。

## 说明

- 无外部 JS 依赖：文字遮罩用 SVG `clipPath`，坠落页是自写的确定性物理（高度图堆叠），轨迹页用原生 pointer 事件。
- 支持 `prefers-reduced-motion`：片头不放大、坠落页保持静态、轨迹页铺成静态词阵。
- 图片素材来自新华社报道截帧与公开资料，仅作课堂展示使用。
